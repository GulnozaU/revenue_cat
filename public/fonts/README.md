# Local font library

Fonts were curated from [Fontshare](https://www.fontshare.com/) (Indian Type Foundry).

- **ITF Free Font License (itf_ffl)** — free for personal & commercial use; self-hosting in apps/websites allowed. See https://www.fontshare.com/licenses/itf-ffl
- **SIL Open Font License (sil_ofl)** — free for personal & commercial use; redistribution allowed. See https://www.fontshare.com/licenses/sil-ofl

FontSpace was used only for aesthetic research. No FontSpace files are bundled (licenses vary and are often unclear).

Do not replace these files with CDN hotlinks at runtime — the editor needs offline/reliable rendering.
